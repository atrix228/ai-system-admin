🖥️ Agent Admin — Privacy Policy

Effective Date: October 29, 2026

Summary: Agent Admin connects to YOUR servers using credentials YOU provide. Server credentials are stored locally on your device. AI diagnostics are processed through your own configured API endpoint. We do not collect, store, or transmit any of your data to our servers.

1. Information We Collect

None. Agent Admin does not collect any personal data or usage analytics. All data stays on your device and your own infrastructure.

2. Data Stored on Your Device

The following data is stored locally on your device using an encrypted local database:

  • Server credentials — hostnames, IP addresses, ports, usernames, passwords, and SSH keys you configure
  • Command logs — history of commands executed on your servers
  • API configuration — your AI provider API key and endpoint URL
  • App preferences — settings such as check intervals and auto-fix toggles

This data:

  • Never leaves your device except to connect to servers and APIs you configure
  • Is not accessible to us or any third party
  • Is deleted when you uninstall the app

3. Network Connections

Agent Admin makes the following network connections, all initiated by you:

  • SSH connections — to servers you add, using credentials you provide. Connections are made directly from your device to your servers.
  • AI API calls — diagnostic data (server stats like CPU/RAM/disk usage) is sent to your configured AI endpoint for analysis. By default, this is your own Evia API instance. We do not operate this endpoint.
Important: The app connects ONLY to servers and API endpoints that YOU configure. We do not operate any backend servers and have no access to your connections.

4. SSH Security

SSH credentials (passwords and private keys) are stored in the app's local database on your device. We recommend:

  • Using SSH key authentication instead of passwords where possible
  • Using dedicated service accounts with limited permissions for AI System Admin
  • Enabling device lock screen protection

5. AI Diagnostics

When you use the AI Diagnose feature, the app sends server statistics (CPU usage, RAM usage, disk usage, uptime, OS info) to your configured AI API endpoint. This data:

  • Is sent only when you explicitly tap the "AI Diagnose" button (or enable auto-check)
  • Goes to YOUR API endpoint, not ours
  • Does not include passwords, SSH keys, or other credentials

6. Third-Party Services

Agent Admin does not integrate any third-party analytics, advertising, or tracking SDKs. The only external connections are those you explicitly configure (your SSH servers and your AI API endpoint).

7. Auto-Fix Feature

If enabled, the auto-fix feature allows the AI to automatically execute commands on your servers to resolve detected issues. This feature is disabled by default and requires explicit opt-in with a confirmation dialog. You are responsible for the commands executed on your servers.

8. Children's Privacy

This app is not directed at children under 13. It is a professional system administration tool.

9. Changes to This Policy

If we update this privacy policy, the changes will be posted on this page with an updated effective date.
